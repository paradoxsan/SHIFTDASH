# Niche Research — Two Rounds, Same Niche, Increasing Depth

Research is what separates a site designed *for this business* from a template with the logo
swapped. Both rounds study the SAME niche; Round 1 is wide, Round 2 is aimed. Each round ends
with a short Hebrew summary for the user and a prioritized action list — research that doesn't
turn into decisions isn't finished.

A core principle for both rounds: **analyze decisions, not pages.** Don't catalog what competitor
sites contain — ask *why* they chose it. "Every plumber site leads with an emergency phone number"
is a decision driven by user urgency; that insight transfers. A screenshot doesn't.

---

## Round 1 — Broad niche scan (Phase 2)

Goal: understand the playing field before asking the client sharp questions.

Run searches (Hebrew first, English to supplement) along these tracks:

1. **Niche conventions** — `אתר [נישה] ישראל`, `דף נחיתה [נישה]`, `[niche] website design`.
   What does every site in this niche include? (e.g., for clinics: team credentials + booking;
   for restaurants: menu + hours + Wolt link; for tradesmen: emergency CTA + service area map.)
   Conventions exist because users expect them — break them only deliberately.
2. **Direct competitors (3–5)** — businesses selling the same thing to the same audience,
   ideally in the same geography. For each, note in one line: positioning/tagline, hero
   structure, primary CTA, trust signals (ביקורות, לוגואים, מספרים), and one weakness.
3. **The creative ceiling (1–2 sites)** — in almost every sector, one or two sites sit
   creatively above the rest. Find them. They serve two purposes: they set the quality
   benchmark, AND they tell you what you must NOT accidentally imitate — the client's site
   has to be distinguishable from the best site in the niche.
4. **Audience pain points** — what do customers in this niche complain about / search for?
   Forums, Google reviews of competitors, ChatGPT-style "כדאי לי...?" questions. The hero
   headline almost always comes from here, not from the client's self-description.
5. **Trust currency of the niche** — what makes someone in THIS niche believable? Licenses?
   Before/after photos? Years in business? Known clients? Price transparency? This determines
   the proof section.

**Round 1 output (Hebrew, to the user):** 5–8 bullet summary — the conventions, the competitor
map, the creative ceiling, the pain points — ending with: "מה שזה אומר לאתר שלך: ..." (2–3
implications). Then move to Phase 3 questions.

## Round 2 — Targeted pass (Phase 4)

Run AFTER the client answered the production questions. Same niche, new precision:

1. **The client's actual segment** — re-search with the real geography/audience
   (e.g., not "מאמן כושר" but "מאמן כושר אישי דימונה באר שבע"). Local competitors change the map.
2. **Conversion anatomy of the best pages** — open the 2–3 strongest competitor pages (web_fetch)
   and break down: section order, where the first CTA appears, form length (how many fields),
   what objections they answer and in what order, mobile behavior.
3. **Content gaps the client can own** — claims, proof, or content no competitor uses but the
   client has (from Phase 3 answers). This is where differentiation is cheap.
4. **Visual benchmark refresh** — with the brand feeling the client described, pull 2–3 concrete
   visual references (see `design-references.md`) and state what to borrow from each
   (a layout idea, a type treatment — never the whole look).

**Round 2 output (Hebrew):** prioritized list — "ההחלטות שהמחקר מכתיב": section order, hero
message direction, proof strategy, the differentiation angle, and the visual direction. This
feeds Phase 5 directly.

## If web search is unavailable

Say so explicitly ("אני בונה על ידע כללי בלי מחקר חי — שווה לאמת מול מתחרים אמיתיים"), then use
niche heuristics: service businesses → urgency + trust + one-tap contact; clinics/professionals →
credentials + process + booking; restaurants/retail → sensory visuals + hours/location + menu;
B2B → outcomes + logos + case studies. Ask the user to paste 1–2 competitor URLs or screenshots —
user-provided material replaces Round 1 track 2–3.

## Anti-patterns

- Research theater: ten searches summarized as "השוק תחרותי". Every finding must change a decision.
- Copying the leader: if the plan resembles the creative-ceiling site, redo the differentiation.
- Researching the wrong competitor set: SEO competitors ≠ business competitors. We benchmark
  against who the CUSTOMER compares the client to.
- Skipping Round 2 because Round 1 "was enough" — Round 2 exists because the client's answers
  always change the target.
