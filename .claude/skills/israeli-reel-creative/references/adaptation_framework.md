# Adaptation Framework — Deconstruct → Map → Localize → Script

This is the part that makes the skill worth more than a search engine. Anyone can find a viral reel.
The value is translating its *mechanics* into a specific Israeli brand so the result is a shootable
reel, not "go copy that." Keep the structure that works; swap the content for the brand's; make it
sound and feel Israeli.

## 1. Step 1 — Deconstruct

Break the reference reel into mechanics, not vibes. Pull apart:

- **Hook (first 1–2 seconds):** the exact thing that stops the scroll — a question, a bold claim, a
  visual surprise, a pattern interrupt, text-on-screen. Name which (see §5).
- **Structure:** the pattern carrying it — transformation, before/after, listicle, POV, day-in-the-
  life, satisfying-process, a comedic bit, founder-to-camera (see §6).
- **Sound's role:** is the track driving the edit (beat-synced cuts), setting a mood, or carrying a
  trending audio meme that *is* the joke? This determines whether the sound is swappable.
- **On-screen text rhythm:** how much text, when it appears, how it paces the watch.
- **Why it holds:** the actual retention mechanism — curiosity gap, payoff promise, rhythm,
  relatability, humor. If you can't name why it works, you can't rebuild it.

Write these as one tight paragraph per reference reel. That paragraph is the blueprint.

---

## 2. Step 2 — Map

Now answer, for the target brand, "what is *our* version of each mechanic?"

- Our version of the reveal / the list / the "before" / the punchline.
- Who's on camera (presenter? hands-only? product-only? AI-generated?).
- What we can actually shoot given the assets from intake.

Rule: **keep the structure, change the content.** If the format is a satisfying-process reel, the
brand's process becomes the content (a fade, a plating, a contract signed). Don't import the
competitor's specifics — import the shape.

---

## 3. Step 3 — Localize

Make it Israeli, not translated. Pull specifics from `references/israeli_context.md`:

- **Hebrew that sounds native** — write the copy in Hebrew from scratch; never translate an English
  hook word-for-word. Israeli phrasing, slang where the brand voice allows, the right register for
  the audience (periphery vs Tel Aviv vs religious sector).
- **References & humor** that land here.
- **RTL on-screen text** conventions and length (short, punchy).
- **Holiday/seasonal hook** if the timing fits — riding Pesach, Mimouna, Yom Ha'atzma'ut, summer,
  back-to-school turns a generic concept into a timely one.

---

## 4. Step 4 — Script

Turn the mapped, localized concept into something an editor or the AI pipeline can execute:

- **Hook line** (the spoken or on-screen opener).
- **Beat-by-beat shot list** — each beat: what's on screen, camera/movement, duration feel.
- **Hebrew on-screen text** per beat.
- **Sound rec** — trending (with link) or suggested, and whether cuts sync to the beat.
- **Caption + hashtags** in Hebrew.
- **Production level** — low (phone, one take), live-action (planned shoot), or AI-generated (hand to
  Higgsfield/Veo/Nano Banana with the prompt).

This is exactly what fills a concept card in `references/brief_template.md`.

## 5. Hook taxonomy

The first 1–2 seconds decide the reel. Common hooks that work, to name in Deconstruct and reuse in
Script:

- **Bold claim / contrarian:** "המספרה הזאת תשנה לכם את התספורת לתמיד."
- **Curiosity gap:** "מה שאף ספר לא יספר לכם על..."
- **Question to the viewer:** "כמה פעמים ביקשתם תספורת ויצאתם מאוכזבים?"
- **Pattern interrupt / visual surprise:** an unexpected action or cut in frame one.
- **Before/after tease:** the "after" flashed first, then "ככה הגענו לזה."
- **Number/listicle:** "3 דברים ש..."
- **POV:** "POV: נכנסת למספרה ו..."
- **Relatable callout:** naming the viewer's exact pain in the first line.

Match the hook to the goal: foot-traffic and awareness reward bold/relatable; leads reward
curiosity-gap and pain-callout.

## 6. Common reel-structure patterns

Durable shapes that carry short-form, with the brand-content swap in mind:

- **Transformation / before→after** — strongest for visual services (barber, beauty, renovation,
  food plating). Tease the after, show the process fast, land the after.
- **Satisfying process** — beat-synced steps of the craft; minimal talk, great with trending audio.
- **Listicle ("N things")** — fast value, text-driven; good for authority niches (law, finance).
- **POV / scenario** — relatable setup the audience lives; humor or empathy.
- **Day-in-the-life / behind-the-scenes** — builds trust and locality; great for SMBs with a face.
- **Founder/expert to camera** — a single strong claim + payoff; good for leads and authority.
- **Comedic bit / trend meme** — rides a specific trending audio; the sound is the format, so it
  expires — move fast or skip.

## 7. Worked examples

### Example A — Barber (e.g. a Be'er Sheva / Negev barbershop)

- **Reference format (deconstructed):** a satisfying transformation reel — hook is the rough "before"
  held for one beat, then beat-synced cuts of the cut/fade, payoff on the clean "after"; trending
  upbeat audio drives the cuts; minimal text. Holds attention via the payoff promise + rhythm.
- **Map:** before = the client walking in; process = clippers, fade, line-up in quick synced cuts;
  after = the reveal turn. On camera: hands + client, no presenter needed (fits "no face" assets).
- **Localize:** Hebrew on-screen hook "מ-0 ל-100 בכיסא הזה"; periphery-friendly warm-but-proud tone;
  if near a holiday, "תספורת לפני החג" angle.
- **Script (sketch):** Hook (0–1s): rough before, text "מ-0 ל-100". Beats (1–8s): 4–5 synced cuts of
  the fade. Payoff (8–10s): reveal turn + smile, text "תורים בלינק". Sound: trending track (link from
  research) or suggested. Caption: "כל תספורת היא סטייטמנט 💈 לתאם תור: ...". Production: live-action,
  low effort, one client.

### Example B — Neighborhood restaurant / shawarma joint

- **Reference format:** POV food reel — hook is a first-person "POV: you walk in hungry," fast cuts of
  the food being made and stacked, ASMR-ish sound, ending on the loaded plate. Holds via craving +
  relatability.
- **Map:** POV of a customer; process = the meat, the pita fill, the toppings; payoff = the overflowing
  plate/pita. Real location footage (asset-dependent).
- **Localize:** Hebrew hook "POV: נכנסת רעב אחרי יום עבודה"; local pride angle; Mimouna/חג tie-in if
  timed; the universal Israeli "טרי מהפלאנצ'ה" energy.
- **Script (sketch):** Hook (0–1s): POV through the door, text "POV: רעב". Beats (1–7s): synced cuts —
  meat, fill, toppings. Payoff (7–10s): the plate, text "כתובת + שעות". Sound: trending or ASMR. CTA in
  caption: hours + location. Production: live-action at the shop.

### Example C — Boutique law firm (authority niche, lead-gen)

- **Reference format:** founder-to-camera listicle — hook is a contrarian claim, three crisp value
  points as on-screen text, payoff is a clear CTA. Holds via authority + curiosity.
- **Map:** the lawyer to camera; three things people get wrong about [the firm's practice area]; CTA to
  DM/consult. Presenter required (asset check).
- **Localize:** Hebrew, authoritative-but-accessible register; concrete, no legalese; "3 דברים שאתם
  חייבים לדעת לפני ש..." structure; trust signals over hype.
- **Script (sketch):** Hook (0–2s): claim to camera + text "3 טעויות שעולות לכם ביוקר". Beats (2–9s):
  three points, each a line of on-screen text + a sentence to camera. Payoff (9–12s): "לשיחת ייעוץ —
  בלינק". Sound: subtle/under-voice (so cuts don't need to beat-sync). Production: live-action,
  single setup, or AI-presenter if no face.

Each sketch is the seed; the full brief expands it into the card format in
`references/brief_template.md`, with the AI-generation prompt attached where the concept is
AI-produced.
