### מה שונה מהגרסה הראשונה של הענף, ולמה (replay)
- **הוסר "שקט בזמן שמחכים לנציג"** (hold): היה משתיק **~1,800 תשובות אמיתיות** (סיכומי הזמנה, הצעות
  מחיר, אישורי מידות). הבוט כותב "נציג יחזור" גם בתשובות שבהן הוא ממשיך למכור. במקומו בא ה-Repeat
  Guard, שחוסם רק את ההבטחה החוזרת עצמה.
- **הוסר "הבוט חזר על אותה שורה פעמיים → להעביר לנציג"** (bot_loop): נדלק 176 פעמים, כמעט תמיד על
  שאלת מכירה רגילה שנשאלה שוב, ופעם אחת על ה"כן" שמאשר הזמנה.
- **Repeat Guard לא מעביר לנציג על שאלה חוזרת**: 263 מ-646 החסימות בגרסה הקודמת היו "דרייפיט או כותנה?" וכדומה.
- **השהיה 120 דק', לא 90**: הבוט החי כבר עבד עם שעתיים (החלטת הבעלים מ-2026-08-07), והמסמך הקודם
  טעה כשכתב 30. 90 דקות היו מקצרות את ההשהיה. מעל 125 דק' `Rep: Stamp` (V2.40.0) מפסיק לתת לבוט לענות אחרי 15 דק' שקט.
- **תלונה נבדקת רק על משפטים שאינם שאלה**, ו"חסר לי מידות / גיליון / הורים" (לפני מכירה) לא נחשב תלונה.
- **"לא שולמה" / "לא שילמת" / "איך שילמת"** כבר לא משתיקים עד חצות.
- **כל node חדש נכשל פתוח**: אם `Friction Gate` או `Repeat Guard` זורקים שגיאה, הבוט עונה כמו לפני V2.42.0.

### מה אסי צריך לדעת
- לא צריך ללמוד מילות קוד. "ההזמנה מוכנה", "מחר יהיה מוכן", לינק תשלום וכו' משתיקים את הבוט עד חצות.
  כל הודעה אחרת שלו משתיקה לשעתיים, ואחרי 15 דקות שקט הבוט עונה ללקוח שכתב (כמו היום).
- **🤖 בצ'אט מחזיר את הבוט מיד.** הלקוח רואה את ה-🤖.
- **בקבוצת ההזמנות**: השבה (reply) על כרטיס עם **"בוט"** מחזירה את הבוט ללקוח, ועם **"שקט"** משתיקה עד חצות.

## 3. החיבור ב-n8n (מה שהסקריפט עשה)
סקריפט הפריסה: `BOT DASHBOARD/n8n/scratch/takeover/apply-v2420.mjs` (dry-run כברירת מחדל, `--put` פורס,
מאמת את הגרסה המפורסמת ומחזיר לאחור לבד אם משהו נכשל). גיבוי של V2.41.2 נשמר באותה תיקייה.
1. `IF Agent Replied` → **`Takeover: Read Current`** (human_mode של הצ'אט, Always Output Data) → `Classify Takeover` (קוד חדש) → `Mark Human Mode` (עכשיו כותב `active` מה-node, כדי ש-🤖 יכתוב false).
2. `Language Gate (Hebrew)` → **`Friction Gate`** → **`IF Friction: Continue?`**: true → הסוכן; false → `Friction: Reply Customer`, `Friction: Silence` (12 שעות), `Friction: Notify Group`, `Friction: Save Turn` (שומר ל-chat_messages את הודעת הלקוח ואת התשובה). ההיסטוריה נלקחת מ-`Mem: Load History` שכבר רץ באותו תור.
3. `Parse Order` → **`Repeat Guard`** → **`IF Repeat Blocked?`**: false → `Send Summary / Reply` (כרגיל); true → `Mem: Save Silenced Inbound` + `IF Repeat: Alert?` → `Repeat: Notify Group`.
4. `Webhook (WHAPI In)` → **`Group Cmd: Filter`** (הקבוצה + from_me + לא api + טקסט) → `Group Bot Command` → `Group Cmd: Set Human Mode` + `Group Cmd: Confirm`.
